About This Project

Project Overview

This is an Angular Film Collection Application – a modern web application built with Angular that allows users to browse, search, and manage their favorite films. The project demonstrates core Angular concepts and best practices in web development.

Course Information

This project was created as part of the Angular Introduction Task from RS School – a free, community-driven educational platform for learning JavaScript and web development.

Task Details: View the original task on GitHub

Key Features

  • search Search & Filter – Find films by title or genre
  • favorite Favorites Management – Add and remove films from your favorites
  • details Detailed View – View comprehensive information about each film
  • brightness_4 Dark Mode Support – Comfortable viewing in any lighting condition
  • speed Modern Technology Stack – Built with latest Angular features

Learning Objectives

Through this project, I have demonstrated proficiency in:

  • Building standalone Angular components
  • Working with Angular Signals for state management
  • Implementing routing and navigation
  • Managing application state with computed signals
  • Using Angular pipes for data transformation
  • Implementing search and filter functionality
